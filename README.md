# Flynn James Pontino Portfolio - AI Chatbot

A secure, production-ready AI chatbot for Flynn's portfolio website with Gemini AI integration.

## Features

- 🔒 **Secure API key management** - Keys stored only on backend
- 🤖 **Gemini AI integration** - Powered by Google's latest models
- 💬 **Conversation memory** - Remembers context across questions
- 📱 **Fully responsive** - Works on all devices
- ⚡ **Quick actions** - One-click questions
- 🛡️ **Rate limiting** - Prevents abuse
- 📊 **Fallback system** - Works even without API
- 🎨 **Beautiful UI** - Dark theme with smooth animations
